Aide, méthode & raccourcis

4 règles d'or pour accélérer l'indemnisation
  1. Zéro affect, 100 % factuel. « Délai d'intervention de 6 jours » plutôt que « un temps interminable ».
  2. Un fait = une preuve. Chaque ligne clé porte une pièce numérotée (PJ-01, PJ-02…).
  3. Isolez vos questions. Une question listée à part obtient une réponse écrite ; noyée dans un mail, elle est ignorée.
  4. Nommage strict des fichiers. Copiez le nom généré (PJ-01_2026-09-12_Nom.pdf) pour renommer vos PDF.
